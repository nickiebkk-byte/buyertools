# BUYER CALCULATOR

เว็บแอปคำนวณสำหรับ Buyer — 40 สูตรสำเร็จรูป พร้อมเมนูตั้งสูตรเอง

## ไฟล์สำหรับอัปโหลด

- `index.html` คือเว็บแอปทั้งระบบ พร้อมฟอนต์ Prompt ที่ฝังในไฟล์
- `.nojekyll` สำหรับให้บริการไฟล์แบบ static
- `README.md` คือคู่มือนี้

## ขึ้น GitHub Pages

1. แตกไฟล์ ZIP ก่อน ไม่ต้องอัปโหลด ZIP
2. เปิด Repository ที่ต้องการ แล้วอัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์นี้ไว้ที่ชั้นนอกสุดของ Repository
3. ต้องเห็น `index.html` อยู่ชั้นนอกสุด ไม่ต้องใส่ในโฟลเดอร์ assets หรือซ้อนในโฟลเดอร์ BUYER-CALCULATOR-GITHUB
4. เปิดใช้งาน GitHub Pages ของ Repository โดยเลือกเผยแพร่จาก branch ที่อัปโหลด และโฟลเดอร์ราก
5. รอการเผยแพร่เสร็จ แล้วเปิด URL ที่ GitHub Pages แสดงให้

ถ้ามี index.html เดิม ให้แทนที่ไฟล์เดิมด้วยเวอร์ชันนี้

## การใช้งาน

- เปิด index.html ในเบราว์เซอร์เพื่อลองแบบออฟไลน์ได้
- รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ
- ทุนกรอก Ex VAT ราคาขายรวม VAT และถอด VAT ก่อนคำนวณกำไร
- ข้อมูลที่กรอกและสูตรที่สร้างเองบันทึกบนเบราว์เซอร์ของอุปกรณ์นั้น ไม่มีฐานข้อมูลส่วนกลาง
- เมื่อเปลี่ยนจากเปิดไฟล์ในเครื่องไปใช้ URL ข้อมูลเดิมจะไม่ย้ายตามอัตโนมัติ
- ยังไม่มีระบบล็อกอินหรืออนุมัติผู้ใช้
